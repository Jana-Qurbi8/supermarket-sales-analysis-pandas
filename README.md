# Supermarket Sales Analysis using Pandas 🛒

A beginner-friendly project using Python and Pandas to explore supermarket sales data and answer business questions.

## What the Notebook Covers

- Dataset exploration and missing-value checks.
- Descriptive statistics for sales.
- Total sales by branch, city, and product line.
- Payment-method frequency and average customer ratings.

## Project Files

- [`supermarket_sales_analysis.ipynb`](supermarket_sales_analysis.ipynb) — Analysis notebook.
- [`SuperMarket Analysis.csv`](SuperMarket%20Analysis.csv) — Dataset used in the notebook.

## Getting Started

Open the notebook in Jupyter with Pandas installed. Keep the CSV in the same folder as the notebook, then run the cells in order.
